*資金調達・提携・製品発表・政策*

今週の国内ビジネス動向は、自動運転と産業用ロボットの規制整備と技術実用化が中心となった。国連が2026年6月にレベル4自動運転の国際安全基準を採択する方針を固めたことを受け[国連、自動運転の安全基準を6月採択へ 「レベル4」想定で初](https://xtech.nikkei.com/atcl/nxt/column/18/03367/042700023/)、日本でも事故時の刑事責任明確化[自動運転時の事故、刑事責任を明確化して事業リスク減らせ](https://xtech.nikkei.com/atcl/nxt/column/18/00138/050702013/)が議論され、関連企業の事業リスク低減と市場拡大が期待される。一方、スタートアップ「人機一体」は鉄道メンテナンスで実績のある人型重機の制御技術を市販ロボットに転用する取り組みを進めており[「まるで一反もめん」と話題の“人型重機” JRも活用する技術を市販ロボに 国産スタートアップ人機一体](https://www.itmedia.co.jp/news/articles/2605/08/news061.html)、Embodied AIの産業応用が加速している。これらの動きは、日本のロボット・自動運転産業が国際基準に適合しつつ、既存ハードウェアとの融合で実用化を推し進める転換点にあることを示している。

**1. [国連、自動運転の安全基準を6月採択へ 「レベル4」想定で初](https://xtech.nikkei.com/atcl/nxt/column/18/03367/042700023/)**
> 世界初となる公道走行想定のレベル4自動運転国際基準が策定され、日本の法規整備や市場拡大に直接的な影響を与える。

## Research Frontier
*今週の注目論文 — 未来を拓く研究*

今週のロボティクス・具身AI分野では、大規模視覚・言語・行動（VLA）モデルの計算効率化と実環境適応が大きな焦点となっている。特に、言語注釈なしでの連合学習[ForgeVLA: Federated Vision-Language-Action Learning without Language Annotations](http://arxiv.org/abs/2605.07474v1)や状態表現キャッシュによるリアルタイム推論[CSR: Infinite-Horizon Real-Time Policies with Massive Cached State Representations](http://arxiv.org/abs/2605.07325v1)といった手法が、モデルの実用化障壁を下げている。また、長期ホライズンの組立タスク[BrickCraft: Visuomotor Skill Composition with Situated Manual Guidance for Long-Horizon Interlocking Brick Assembly](http://arxiv.org/abs/2605.07605v1)や物体指向のワールドアクションモデル[OA-WAM: Object-Addressable World Action Model for Robust Robot Manipulation](http://arxiv.org/abs/2605.06481v1)の登場により、複雑な物理環境でのマニピュレーションの堅牢性が飛躍的に向上しつつある。これらの動向は、単なるモデル規模の拡大から「実環境での低遅延・高適応性・物理整合性」へのパラダイムシフトを示している。

**トレンド:** `VLA/ワールドモデルの推論効率化とリアルタイム制御の実現` / `長期ホライズンマニピュレーションのためのスキル構成と適応制御` / `物理情報統合とSim2Realギャップ解消のための動的モデリング`

**1. [ForgeVLA: Federated Vision-Language-Action Learning without Language Annotations](http://arxiv.org/abs/2605.07474v1)**
> 言語注釈の不要な連合学習により、実環境データを活用したVLAモデルの低コスト・高スケーラブルな学習を実現。

本研究は、視覚・言語・行動（VLA）モデルの学習における言語アノテーションの依存性を解消する連合学習フレームワークを提案する。従来のVLAモデルは高品質な言語指示データに強く依存していたが、本手法は実環境で収集された大量の視覚データのみを用いて分散学習を行うことで、アノテーションコストを大幅に削減する。各エージェントはローカルデータでモデルを更新し、中央サーバーに生データを送信することなく知識を共有するため、プライバシー保護と通信効率の両立が図られる。実験では、限られた言語データでも実環境での汎化性能が維持されることが示されており、実用ロボットへの大規模デプロイメントの足がかりとなる。特に、多様なハードウェアプラットフォーム間での知識転移が容易になる点が実務的に重要である。このアプローチは、データ収集のハードルを下げながらモデルの汎用性を高めるため、産業現場でのVLA導入を加速させる可能性を秘めている。

本研究は、長期にわたる精密な組立タスクをロボットが自律的に実行するためのBrickCraftフレームワークを提示する。従来のアプローチではタスクの長期依存性や微細な位置合わせで性能が頭打ちになる課題があったが、本手法は視覚運動スキルをモジュール化し、状況に応じた手動ガイダンスと組み合わせることでこの問題を克服する。空間認識モデルがブロックの配置状態を把握し、微細な操作ポリシーが接触力や位置補正を制御する二段階アーキテクチャを採用している。これにより、誤差の蓄積を防ぎつつ、人間のような柔軟な組立動作を可能にする。実機実験では、複雑なインターロッキング構造の組立成功率が従来法を大幅に上回り、実用的な製造・組立現場への応用可能性を強く示唆している。手動ガイダンスの介入頻度を最小限に抑える設計により、人間の負担を軽減した半自律型作業システムの構築にも直接貢献する。

**3. [CSR: Infinite-Horizon Real-Time Policies with Massive Cached State Representations](http://arxiv.org/abs/2605.07325v1)**
> 大規模状態表現をキャッシュする新手法により、VLAモデルの推論遅延を解消し、無限ホライズンのリアルタイム制御を実現。

具身AIの実環境デプロイメントにおける最大のボトルネックの一つである大規模モデルの推論遅延に対し、本論文は状態表現をキャッシュするCSR手法を提案する。従来のVLAモデルは各ステップで重い言語・視覚エンコーダを再計算する必要があったが、本手法は過去の状態表現を効率的に保存・再利用することで、計算負荷を劇的に低減する。これにより、モデルの推論速度が実時間制御の要件を満たすようになり、無限ホライズンのタスクでも文脈の整合性を保ったまま高速応答が可能となる。キャッシュ戦略はメモリ使用量と推論精度のトレードオフを最適化しており、エッジデバイス上での実行も現実的になる。ロボット制御の実用性を決定づける「応答性」と「安定性」を両立する画期的なアプローチである。特に、長時間の自律作業において文脈の忘却や計算リソースの枯渇を防ぐ点で、実用ロボットの稼働時間を大幅に延伸する基盤技術となる。

**4. [OA-WAM: Object-Addressable World Action Model for Robust Robot Manipulation](http://arxiv.org/abs/2605.06481v1)**
> 物体指向の表現を採用したワールドアクションモデルにより、マニピュレーションタスクの環境遷移予測精度と制御堅牢性を飛躍的に向上。

本研究は、従来の全体画像予測に依存するワールドアクションモデル（WAM）の限界を克服するため、物体指向の構造化表現を導入するOA-WAMを提案する。背景や不関連な視覚ノイズの影響を受けにくく、アクションデコーダが直接利用可能な明確な環境遷移予測を実現する。各物体の状態変化を個別に追跡することで、接触や把持などの物理的相互作用をより正確にモデル化できる。これにより、複雑なマニピュレーションタスクにおける計画の失敗率が低下し、未知の物体配置や照明変化に対するロバスト性が大幅に向上する。シミュレーションおよび実機評価で、既存のWAMを凌駕する性能を示しており、具身エージェントの自律操作能力を次の段階へ引き上げる基盤技術となる。構造化された予測表現は、モデルの解釈可能性も高めており、失敗時の原因究明や安全保証の観点からも実環境導入に極めて有利である。

*— arXiv*
