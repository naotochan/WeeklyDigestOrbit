How tactile sensing improves model performance

視覚言語行動（VLA）モデルの把持課題を解決するため、触覚フィードバックを統合するVTAM手法の性能向上効果を実証。

現在の視覚言語行動（VLA）モデルは、滑りやすい物体や形状が複雑な繊細なアイテムの把持において、視覚情報のみでは制御が不安定になる課題を抱えている。Robotiqと研究チームは、この課題を解決するためにVideo Tactile Action Model（VTAM）を開発し、触覚センシングデータをモデル入力に統合する手法を提案した。VTAMは、グリッパーの指先に設置された高解像度触覚センサーから得られる圧力分布や滑り検知信号を、動画フレームと同期して処理することで、把持中の微細な状態変化をリアルタイムで把握できる。実験結果では、触覚情報を加えることで把持成功率が大幅に向上し、特に透明物体や変形しやすい軟体物に対する操作精度が顕著に改善されたことが示された。この技術は、ロボットハンドのハードウェア仕様を大幅に変更することなく、既存のVLAモデルにソフトウェアレベルで触覚モジュールを追加するだけで適用可能である。マルチモーダルセンシングの統合は、Physical AIが実世界の物理法則をより正確に理解するための重要なマイルストーンとなる。

Why traditional robotics data collection is obsolete and what replaces it

従来の手動データ収集の限界を指摘し、動画データを活用した自律的・スケーラブルな学習パイプラインへ移行する必要性を提唱。

Rhoda AIのEric Chan氏は、Embodied AIの発展を阻むボトルネックの一つが、従来のロボットデータ収集手法の非効率性であると指摘している。従来は専門家がロボットを遠隔操作してデモデータを記録する手法が主流だったが、この方法は人的コストが高く、収集できるデータの種類や量に明確な上限が存在する。同氏は、この限界を打破するために、公開されている大量の動画データやシミュレーション環境から自律的にタスク構造を抽出する新しいアプローチの重要性を強調した。動画データを活用すれば、特定のロボットハードウェアに依存せず、多様な環境や操作手法を含む広範な知識を低コストで学習モデルに注入できる。さらに、収集されたデータは自動で品質評価・フィルタリングされるAI駆動型パイプラインと組み合わせることで、学習効率を最大化できる。このデータ収集パラダイムの転換は、Embodied AIが研究段階から実用・量産段階へ移行する上で不可欠なインフラ変革である。

ForgeVLA: Federated Vision-Language-Action Learning without Language Annotations

言語注釈の不要な連合学習により、実環境データを活用したVLAモデルの低コスト・高スケーラブルな学習を実現。

本研究は、視覚・言語・行動（VLA）モデルの学習における言語アノテーションの依存性を解消する連合学習フレームワークを提案する。従来のVLAモデルは高品質な言語指示データに強く依存していたが、本手法は実環境で収集された大量の視覚データのみを用いて分散学習を行うことで、アノテーションコストを大幅に削減する。各エージェントはローカルデータでモデルを更新し、中央サーバーに生データを送信することなく知識を共有するため、プライバシー保護と通信効率の両立が図られる。実験では、限られた言語データでも実環境での汎化性能が維持されることが示されており、実用ロボットへの大規模デプロイメントの足がかりとなる。特に、多様なハードウェアプラットフォーム間での知識転移が容易になる点が実務的に重要である。このアプローチは、データ収集のハードルを下げながらモデルの汎用性を高めるため、産業現場でのVLA導入を加速させる可能性を秘めている。

BrickCraft: Visuomotor Skill Composition with Situated Manual Guidance for Long-Horizon Interlocking Brick Assembly

視覚運動スキルの構成と現場手動ガイダンスを統合し、長期ホライズンの複雑なブロック組立タスクを高精度に遂行。

本研究は、長期にわたる精密な組立タスクをロボットが自律的に実行するためのBrickCraftフレームワークを提示する。従来のアプローチではタスクの長期依存性や微細な位置合わせで性能が頭打ちになる課題があったが、本手法は視覚運動スキルをモジュール化し、状況に応じた手動ガイダンスと組み合わせることでこの問題を克服する。空間認識モデルがブロックの配置状態を把握し、微細な操作ポリシーが接触力や位置補正を制御する二段階アーキテクチャを採用している。これにより、誤差の蓄積を防ぎつつ、人間のような柔軟な組立動作を可能にする。実機実験では、複雑なインターロッキング構造の組立成功率が従来法を大幅に上回り、実用的な製造・組立現場への応用可能性を強く示唆している。手動ガイダンスの介入頻度を最小限に抑える設計により、人間の負担を軽減した半自律型作業システムの構築にも直接貢献する。

CSR: Infinite-Horizon Real-Time Policies with Massive Cached State Representations

大規模状態表現をキャッシュする新手法により、VLAモデルの推論遅延を解消し、無限ホライズンのリアルタイム制御を実現。

具身AIの実環境デプロイメントにおける最大のボトルネックの一つである大規模モデルの推論遅延に対し、本論文は状態表現をキャッシュするCSR手法を提案する。従来のVLAモデルは各ステップで重い言語・視覚エンコーダを再計算する必要があったが、本手法は過去の状態表現を効率的に保存・再利用することで、計算負荷を劇的に低減する。これにより、モデルの推論速度が実時間制御の要件を満たすようになり、無限ホライズンのタスクでも文脈の整合性を保ったまま高速応答が可能となる。キャッシュ戦略はメモリ使用量と推論精度のトレードオフを最適化しており、エッジデバイス上での実行も現実的になる。ロボット制御の実用性を決定づける「応答性」と「安定性」を両立する画期的なアプローチである。特に、長時間の自律作業において文脈の忘却や計算リソースの枯渇を防ぐ点で、実用ロボットの稼働時間を大幅に延伸する基盤技術となる。

OA-WAM: Object-Addressable World Action Model for Robust Robot Manipulation

物体指向の表現を採用したワールドアクションモデルにより、マニピュレーションタスクの環境遷移予測精度と制御堅牢性を飛躍的に向上。

本研究は、従来の全体画像予測に依存するワールドアクションモデル（WAM）の限界を克服するため、物体指向の構造化表現を導入するOA-WAMを提案する。背景や不関連な視覚ノイズの影響を受けにくく、アクションデコーダが直接利用可能な明確な環境遷移予測を実現する。各物体の状態変化を個別に追跡することで、接触や把持などの物理的相互作用をより正確にモデル化できる。これにより、複雑なマニピュレーションタスクにおける計画の失敗率が低下し、未知の物体配置や照明変化に対するロバスト性が大幅に向上する。シミュレーションおよび実機評価で、既存のWAMを凌駕する性能を示しており、具身エージェントの自律操作能力を次の段階へ引き上げる基盤技術となる。構造化された予測表現は、モデルの解釈可能性も高めており、失敗時の原因究明や安全保証の観点からも実環境導入に極めて有利である。
