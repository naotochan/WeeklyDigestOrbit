動きを先読みして触覚で状況を判断　新たなロボット基盤モデル「RLDX-1」とは

従来のVLAを超える、物理的な動きの予測と触覚情報を用いた判断が可能な次世代ロボット基盤モデルが発表された。

詳細

韓国のフィジカルAIスタートアップRLWRLDが開発した「RLDX-1」は、単なる視覚や言語処理に留まらない高度な知能を備えています。このモデルの最大の特徴は、「動きを先読みする能力」と「触覚情報を用いた状況判断」を統合している点です。従来のVLA（Vision Language Action）が入力されたデータに基づいて動作を生成するのに対し、RLDX-1は物理法則に基づいた予測を行い、より現実世界に近い自律的な意思決定を可能にします。これにより、複雑な環境下での物体操作や人との協調作業において、高い信頼性と柔軟性が期待されています。これは、ロボットが単なるツールではなく、周囲の状況を深く理解する「身体」を持つことを意味します。

ヒューマノイド実用化の鍵「世界モデル、数年以内に実現も」

ロボットの実用化には、物理世界の現象を予測し意思決定を行う「世界モデル」の構築が不可欠であると専門家は指摘した。

詳細

ヒューマノイドや汎用ロボットを実社会で活用するためには、単に大量のデータからパターンを学習するLLM（大規模言語モデル）だけでは不十分です。必要なのは「世界モデル」であり、これは物理法則に基づいた因果関係や現象の予測能力を持つAI技術です。世界モデルは、「もしAという行動をとったら、Bという結果が起こるだろう」といった形で、物理的なシミュレーションを内部で行うことを可能にします。これにより、予期せぬ事態が発生した際にも、ロボットが自律的に最適なリカバリー動作を計画できるようになります。専門家たちは、この世界モデルの実現こそが、真に汎用性の高いAIエージェントを生み出す鍵であると強調しています。

生成AIを活用することで、プログラミング知識がなくても自然言語からPythonコードを介して産業用ロボットの操作が可能になった。
